# Православний календар

Мобільний застосунок для **Android та iOS** (Expo / React Native, TypeScript) за макетом
[Orthodox Calendar v2](https://claude.ai/design/p/8361aa27-72af-4779-8aac-372c7d47faea?file=Orthodox+Calendar+v2.dc.html)
(дизайн-система «Classical»: Cormorant Garamond + Lora, золотий акцент, денна й нічна теми).

## Що є

- **Сьогодні** — пам'ять дня, піст, читання (Апостол, Євангеліє), іменини, тиждень із позначками.
- **Календар** — місяць із навігацією, позначки свят і постів, список Двонадесятих і великих свят.
- **Молитвослов** — дев'ять розділів (правило, початкові молитви, Причастя, акафісти, канони, Часослов, на різні потреби, а також «Молитви Київського ізводу» та «Святі й свята» — тропарі, молитви й ікони святих), акафіст за днем тижня, Ісусова молитва з чотками-лічильником.
- **Письмо** — Євангеліє, Апостол, Псалтир за кафизмами з відміткою прочитаного.
- **Меню** — помʼянник, налаштування (мова uk/en, новоюліанський або юліанський календар, розмір тексту, нагадування), денний/нічний режим, підтримка проєкту, історія версій.
- Пошук по святих, святах і молитвах. Налаштування й прогрес зберігаються на пристрої.

## Запуск

```bash
npm install
npm start          # Expo Dev Tools; відскануйте QR у Expo Go
npm run android    # емулятор Android
npm run ios        # симулятор iOS (потрібен macOS)
npm run typecheck
```


## Обмеження поточної версії

Це порт макета; контент у ньому — зразок, а не повна база.

- **Повний календар є на 2026 і 2027 роки** (`src/data/calendar2026.ts`, `src/data/calendar2027.ts`, див. нижче). Для інших років наповнено тільки жовтень і другу половину вересня (`src/data/calendar.ts`); дані прив'язані до місяця й числа. Для решти днів пам'ять порожня («дані ще не додано»).
- **Читання (Апостол/Євангеліє) для 2026 і 2027 років — справжні, з календаря; для інших років — приклад за днем тижня.**
- Повні тексти ранкових і вечірніх молитов, правила до Причастя, канонів (покаянного, молебного Богородиці, Ангелу Хранителю) і молитов на різні потреби беруться з молитвослова Київського ізводу (`src/data/molytvoslov.ts`). Повних текстів акафістів, Великого й Пасхального канонів, Часослова, Біблії та Псалтиря ще немає: ці екрани показують план читання з позначкою про це.
- **Нагадування:** перемикачі зберігаються, але локальні сповіщення ще не заплановано.
- **Підтримка проєкту:** замініть `JAR_URL` у `src/store.tsx` на справжню банку monobank. QR-код не реалізовано.
- Застосунок зібрано (`expo export` для Android та iOS) і пройшов перевірку типів, але ще не запускався на пристрої чи емуляторі.

## Календар на 2026 і 2027 роки

`src/data/calendar2026.ts` і `src/data/calendar2027.ts` містять усі 365 днів кожного року: пам'ять святих і свята, тиждень по Пʼятидесятниці (або Великого посту чи Світлий тиждень), піст, глас і читання (Апостол, Євангеліє, ранішні й вечірні). Джерело — [azbyka.ru/days/calendar/2026](https://azbyka.ru/days/calendar/2026) і [2027](https://azbyka.ru/days/calendar/2027), текст перекладено українською. Дані юліанські, ключ — цивільна дата.

- **Юліанський режим** показує запис за цивільною датою як на сайті.
- **Новоюліанський режим** (типовий) бере неперехідну пам'ять і постійні пости (Різдвяний, Успенський) за числом місяця, а тиждень, Пасхалію й перехідні свята — за цивільною датою. Тому, наприклад, Різдво припадає на 25 грудня, а Покрова — на 1 жовтня.
- Чого немає: іменин (крім вересня й жовтня з ручних даних) і англійського тексту (англійська версія показує українські назви). Правила їжі в піст обчислюються за рангом свята, як і раніше, а не беруться із сайту.
- Для днів першого тижня Великого посту 2027 року (15–18 березня), 14 квітня 2027 і 24 липня 2026 сайт не наводить звичайних читань, тож їх теж немає.
- Для січня–жовтня 2026 року сайт показує читання в скороченому вигляді (без вказівок на випадок поліелейної служби), тому такі умовні читання в 2026 році пропущено.
- У новоюліанському режимі богослужбові читання і піст у дні Святок та кінця Апостольського посту наближені: перевірте їх за місцевим уставом.

## Джерело молитов і зображень

Розділи VIII–IX Молитвослова (`src/data/channel.ts`, `assets/channel/`) складено з публічного Telegram-каналу [«Київський Ізвод»](https://t.me/kyiv_izvod): тексти молитов, тропарів і величань та зображення святих (стиснені до ≤480 px). Права на тексти й зображення належать їхнім авторам і каналу; перед публічним випуском варто погодити використання з адміністрацією каналу.
