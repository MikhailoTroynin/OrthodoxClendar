# Звірка молитов додатка з azbyka.ru/molitvoslov і перенесення відсутніх

Скрипти й дані, якими молитви сайту [azbyka.ru/molitvoslov](https://azbyka.ru/molitvoslov/#ch1) звірено з додатком і перенесено в розділ XIII «Додаткові молитви». Звіт і рішення — у [docs/prayers-import/AZBYKA.md](../../docs/prayers-import/AZBYKA.md).

Робочий каталог кешу `W` — будь-який порожній каталог поза репозиторієм (кеш займає ≈ 70 МБ).

## 1. Звірка

```bash
python3 -I scripts/azbyka/crawl.py "$W"                    # індекс сторінки й тексти молитов у $W/index.json, $W/pages/<id>.html
python3 -I scripts/azbyka/compare.py "$W" src/data         # $W/units.json (усі уривки сторінок із покриттям), $W/REPORT.md
python3 -I scripts/azbyka/missing.py "$W" src/data         # $W/missing.json, $W/missing_ru.json, $W/MISSING.md — чого немає в додатку
```

- `crawl.py` бере головну сторінку молитвослова (521 позиція) і завантажує всі її сторінки на azbyka.ru/molitvoslov (472); зовнішні посилання (книги на otechnik тощо) пропускає.
- `compare.py` ділить кожну сторінку на уривки за заголовками (h2–h4) і для кожного рахує, яка частка трійок слів є в текстах додатка. Слова зводяться до «скелета», де стерто різницю між російським, церковнослов'янським і українським правописом (е/и/і/ы/ѣ → и, ь/ъ/апостроф геть). Церковнослов'янську частину відділено від російських перекладів і пояснень за наголосами й характерними словами. Покриття ≥ 0,55 — «є», 0,35–0,55 — «частково», нижче — «немає».
- `missing.py` залишає уривки, де покриття < 0,25 і в додатку немає назви з тими самими ключовими словами; псалми, Біблію, словники, дублі церковнослов'янським шрифтом, книги (Тріодь, Октоїх, Афонський молитвослов) і іноземні мови не рахує. Уривки, що вже перенесено (ключі в `manifest_*.tsv`, `tropari_titles.tsv`), у звіт не потрапляють, тож після перенесення звіт показує лише те, що лишилося.

Ключ уривка — `<id сторінки>#<хеш початку тексту>`; він не залежить від порядку в звіті.

## 2. Перенесення

```bash
python3 -I scripts/azbyka/build.py "$W" <каталог scripts навички cs-kyiv-translit> src/data/kz "$W/build_report.json"
```

Пише `src/data/kz/az<N>.ts` (шарди ≤ 450 КБ, вантажаться за потреби) і `azMeta.ts` (перелік: номер, шард, номер у шарді, група, назва, назва англ.). Розділ «Додаткові молитви» (`src/data/prayers.ts`) — останній, тож закладки в наявних розділах не зсуваються.

Що переносити, задають файли:

| Файл | Зміст |
|---|---|
| `manifest_cs.tsv` | уривки церковнослов'янською та церковно-російською: ключ, `T`, група, назва укр., назва англ., заголовок розділу (для книг з кількох уривків) |
| `manifest_ru.tsv` | уривки сучасною російською: те саме, режим `R`; текст — переклад українською |
| `translated/az_*.txt` | переклади для `manifest_ru.tsv`: блок `=== <ключ>` і абзаци (по одному в рядку); `=== <ключ> @N` замінює абзац N у транслітерованому тексті, без рядків — прибирає його (переклад-дубль) |
| `tropari_titles.tsv` | тропарі: ключ, заголовок розділу (книга = сторінка azbyka; назви книг — `KBOOK` у `build.py`) |

Групи: `B` Богородиці, `H` родина, діти й хрещеники, `L` хворі, `M` різні потреби, `U` спочилі, `S` святим, `W` піснеспіви Страсної седмиці, `K` тропарі (порядок = порядок підзаголовків `AZG` у `prayers.ts`).

Транслітерація — навичка `cs-kyiv-translit` (правила віра.укр, режим «гражданка»), з тими самими поправками, що в `scripts/build_kz_akafisty.py` (`тебе/тебі`, `-е/-і` після прийменників, латинські двійники кирилиці, апостроф у `м'я`). До слів зі звіту `ambig` (-и/-і, -ия/-ія тощо) вичитки не було — потрібна вибіркова вичитка редактором, як і для акафістів та канонів (`PLAN.md`).

Щоб додати чи прибрати уривок: знайти його ключ у `$W/MISSING.md`/`missing.json` (поле `key` — `missing.py` пише `id` і `text`; ключ рахує `key_of`), дописати рядок у відповідний файл і перезібрати.
